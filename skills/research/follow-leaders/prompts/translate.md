# How to translate the digest

If the user's configured language is not English, translate the fully-assembled
digest after remixing (not each raw source individually — remix in English first
using the other prompts, then translate the final output).

Rules:

- Keep names, handles, and links untranslated.
- Keep numbers and units as originally stated; only convert currency if the user
  has explicitly asked for that.
- Preserve the section structure from `digest-intro.md` exactly — only the prose
  inside each section is translated.
- Aim for natural, idiomatic phrasing in the target language rather than a literal
  word-for-word translation — a fluent local reader should not be able to tell it
  was translated.
