# Overall digest format and tone

Structure every digest the same way:

1. **Header** — industry name, date range covered, one-line framing (e.g. "Fintech
   Leaders Digest — Jun 30–Jul 6, 2026").
2. **The one thing worth knowing** — 1-2 sentences distilling the single most
   important development or disagreement this period, if one clearly stands out.
   Skip this section entirely rather than force it if nothing rises above the rest.
3. **Podcasts** — using `summarize-podcast.md` rules.
4. **LinkedIn** — using `summarize-linkedin.md` rules.
5. **X/Twitter** — using `summarize-tweets.md` rules.
6. **Instagram / TikTok / Facebook** — using `summarize-social.md` rules (omit empty).
7. **Reddit** — using `summarize-reddit.md` rules.
8. **Sources** — a flat list of every link used, so the reader can go deeper.

Tone: direct, unhyped, written like a sharp colleague's private notes rather than a
newsletter trying to get forwarded. No exclamation points. No "game-changing" or
"revolutionary." If nothing significant happened in a section this period, say so
in one line rather than padding it out ("Quiet week for podcasts — nothing new from
the tracked shows.").

Keep the whole digest skimmable in under 3 minutes. When in doubt, cut rather than
add.
